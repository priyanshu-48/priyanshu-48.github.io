PayLedger: Payments & Double-Entry Ledger

GitHub ↗
Payment service→Outbox→Kafka→Idempotent consumer→Ledger (Postgres)→Recon + Notifications
  • Solo-built payments platform in Java 21, Spring Boot, PostgreSQL and Kafka: a double-entry ledger with append-only journals and balanced entries enforced by database triggers and constraints, and a payment state machine against a stand-in bank.

  • 152 tests, 92.8% line coverage; JWT auth with ownership checks, Spring Batch reconciliation (19/19 planted errors found, 0 false positives), Prometheus/Grafana/Jaeger tracing, Jenkins and GitHub Actions CI.
